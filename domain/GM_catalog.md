# TABC 綠建材採購指南檢索與資料對照規範 (`GM_catalog`)

本文件定義財團法人臺灣建築中心（TABC）綠建材採購指南之檢索對照機制。本規範作為 AI Agent 接收使用者自然語言需求（例如「地板材料」、「隔音牆」、「低毒性塗料」）時，對照至綠建材四大標章與細項品類之標準依據。

---

## 1. 綠建材四大標章分類體系 (Classification Taxonomy)

根據 TABC 綠建材標章審查體系，綠建材分為 **四大標章類別 (`GBMTYPE`)** 與相應的 **細項品類 (`GBMITEM`)**：

### 1.1 健康綠建材 (GBMTYPE = 1)
* **核心定義**：低毒性、低逸散（甲醛與 TVOC）之室內裝修材料。
* **細項品類 (`GBMITEM`)**：
  * `01` 地板類
  * `02` 牆壁類
  * `03` 天花板
  * `04` 填縫劑與油灰類
  * `05` 塗料類
  * `06` 接著(合)劑
  * `07` 門窗類
  * `08` 固定式隔屏或櫥櫃類

### 1.2 高性能綠建材 (GBMTYPE = 2)
* **核心定義**：具備卓越隔音、吸音、透水或節能隔熱等物理性能指標之材料與組件。
* **細項品類 (`GBMITEM`)**：
  * **隔音類**：`01` 隔音(外牆、屋頂板、分戶牆、分間牆)、`02` 隔音(窗戶)、`03` 隔音(門扇)、`04` 隔音(樓板表面材(含緩衝材))、`12` 隔音(昇降機道與居室相鄰之分間牆)、`13` 隔音(橡膠緩衝材)
  * **吸音類**：`05` 吸音(吸音材)
  * **透水鋪面類**：`06` 透水鋪面(單元透水磚透水鋪面)、`11` 現場整體澆置之剛性透水鋪面、`14` 透水鋪面(單元高壓磚透水鋪面)、`15` 透水鋪面(現場整體澆置之柔性透水鋪面)、`16` 透水鋪面(現場整體澆置之剛性透水鋪面)、`17` 透水鋪面(其他型透水鋪面)、`18` 滲透側溝、`19` 滲透陰井、`20` 滲透排水管
  * **節能隔熱類**：`07` 節能(單層玻璃)、`08` 節能(LOW-E玻璃)、`09` 節能(膠合玻璃)、`10` 節能(複層玻璃)、`21` 建築門窗用玻璃貼膜材料、`22` 建築用隔熱材料、`23` 外牆系統或構造、`24` 屋頂系統或構造、`25` 節能塗料、`26` 節能窗戶

### 1.3 再生綠建材 (GBMTYPE = 3)
* **核心定義**：利用國內廢棄物回收再利用製造，符合再生材料利用率標準之建材。
* **細項品類 (`GBMITEM`)**：
  * `04` 再生纖維水泥板、纖維水泥板、纖維強化水泥板
  * `05` 高壓混凝土地磚
  * `06` 混凝土空心磚
  * `07` 混凝土粒料 / `17` 綠混凝土 / `26` 控制性低強度材料 (CLSM)
  * `08` 陶瓷面磚
  * `09` 石膏板
  * `10` 普通磚 / `16` 水泥瓦 / `20` 磨石子板、磨石子地磚
  * `11` 輕質混凝土嵌板 / `19` 輕質發泡混凝土磚 / `27` 輕質隔熱建築材料
  * `12` 水硬性混合水泥 / `13` 裝飾用珠狀粒料
  * `14` 透水性混凝土地磚 / `15` 橡膠鋪面材料
  * `21` 木材-塑膠之再生複合材 (塑木) / `22` 塑膠地磚
  * `23` 隔熱混凝土用輕質粒料 / `24` 建築用隔熱材料 / `25` 屋頂隔熱磚

### 1.4 生態綠建材 (GBMTYPE = 4)
* **核心定義**：採用天然、無毒、低加工、可再生且低環境衝擊之天然資源材料。
* **細項品類 (`GBMITEM`)**：
  * `01` 木製建材 / `02` 天然植物建材
  * `03` 天然隔熱建材
  * `04` 非化學合成管線材 / `05` 非化學合成衛浴
  * `06` 木材染色劑 / `07` 外殼粉刷材 / `08` 塗料
  * `09` 窗簾 / `10` 壁紙 / `11` 填縫劑
  * `12` 其他天然建材 / `13` 天然石材

## 4. 物理與性能規格白話化規範 (Human-Friendly Formatting Rules)

為提升對話體驗與閱讀便利性，所有材料之物理性能、測試數值與規格說明**嚴禁使用艱澀的 LaTeX 數學符號或複雜科學記號**，統一採用建築師與業主易懂的直觀文字與標準工程單位呈現：

| 原物理/科學記號 | 易讀白話文表達範例 | 說明 |
| :--- | :--- | :--- |
| $\ge 1.0 \times 10^{-2}\text{ cm/s}$ | **大於每秒 0.01 公分**（具高透水速率） | 避免使用 $10^{-2}$ 等科學記號 |
| $K \le 0.05\text{ W/m}\cdot\text{K}$ | **低於 0.05 W/m·K**（高隔熱性能） | 使用直觀單位及性能評語 |
| $\le 0.005\text{ mg/m}^2\cdot\text{h}$ | **極低逸散**（每小時每平方公尺小於 0.005 毫克） | 標示健康等級與白話說明 |
| $R_w \ge 50\text{ dB}$ | **隔音量達 50 分貝以上**（符合分戶牆隔音） | 搭配法規防護說明 |

## 5. 綠建材動態檢索展示網頁與關鍵字觸發詢問規範 (Interactive Web Showcase & Trigger Confirmation Rule)

當使用者提及「綠建材」相關提示詞（如：`綠建材`、`綠建材標章`、`牆體綠建材`、`地坪綠建材`、`TABC綠建材`、`健康綠建材`、`高性能綠建材`、`再生綠建材`、`生態綠建材`、`綠建材採購`、`綠建材網頁` 等）時，AI Agent **不得自動開啟網頁**，而是要先詢問使用者是否要開啟 `assets/green-material-showcase.html`（本機產生物，非版控檔；由 /GM_update 從 assets/green-material-showcase.template.html 產生，見 tools/green-material/README.md）；使用者確認後，才執行 `/GM_web open`（見 `.claude/skills/GM_web/SKILL.md`）。若使用者的訊息本身已經是明確的開啟請求（例如直接輸入 `/GM_web open` 或「開啟綠建材檢索平台」），可視為已確認，直接執行，不需要再多問一次。

### 5.1 需求導向 3 步驟動態抓取與 Showcase 更新規範 (3-Step On-Demand Fetch & Dynamic Update Rule)
* **核心作業流程**：
  1. **步驟 1 (接收材料需求與關鍵字觸發)**：接收使用者告知的當前材料需求（如「牆體綠建材」、「塗料/油漆」、「木地板」、「隔音樓板」、「矽酸鈣板」等）後，先詢問是否要開啟綠建材 Showcase 網頁（`/GM_web open`），取得使用者同意後才執行。
  2. **步驟 2 (從原網頁精準抓取相關材料)**：專門從 TABC 綠建材採購指南原網頁真實資料中，擷取屬於該材料類別的真實認證品項物件（包含真實標章核定編號、申請公司、有效期限、白話規格、官方圖片 URI 與驗證頁 URI）。
  3. **步驟 3 (更新 Showcase 網頁並呈現)**：資料庫更新請一律透過 `GM_update_tabc_database.py`（`/GM_update`，見 `.claude/skills/GM_update/SKILL.md`），不要手動零星寫入 `assets/green-material-showcase.html` 的 `tabcDatabase` 陣列；使用者同意開啟網頁後，執行 `/GM_web open` 呈現。

## 6. 互動對話與分析呈現流程 (Standard Execution Steps)

1. **需求對照與詢問是否開啟網頁**：接收使用者綠建材需求後，先詢問是否要開啟 `assets/green-material-showcase.html`（本機產生物，非版控檔；由 /GM_update 從 assets/green-material-showcase.template.html 產生，見 tools/green-material/README.md） 檢索平台；同意後執行 `/GM_web open`。
2. **原網頁真實物件擷取**：撈取/精選該品類下於 TABC 原網頁真實取得 GBM 認證之廠商、建材與圖片。
3. **資料庫更新（如需要）**：主資料庫已過期或缺漏時，透過 `/GM_update` 更新，不手動零星寫入展示網頁。
4. **Revit 共享參數導引**：於展示網頁中提供單鍵「查看 Revit 參數」與批次匯入 Revit 共享參數選項。
