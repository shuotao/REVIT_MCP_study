## 2. DATA Engine 檢索呈現邏輯

1. 當使用者在對話或動態網頁中輸入任意關鍵字（如「牆」）時，DATA Engine 自動執行：
   * **包含比對 (Substring match)**：名稱/細項包含「牆」字的所有真實合格案件全數列出。
   * **同義與部位擴充 (Expansion match)**：自動將石膏磚、牆面裝飾塗材、外牆水泥漆、牆體綠混凝土、重組竹壁板、矽酸鈣板、纖維水泥板全數精準列出。
2. 網頁頂部標示檢索統計 Banner：
   * `✅ 建築 Agent 關鍵字 DATA Engine：共檢索出 [N] 項【包含關鍵字及語意擴充同義材料】之 TABC 官方線上合格案件`
