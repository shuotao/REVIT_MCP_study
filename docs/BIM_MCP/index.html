一句話：BIM_MCP 讓你用講人話的方式操作 Revit——AI 讀懂需求，透過 239 個工具直接改模型、查資料、跑法規檢核。

三層：Skill（61・何時觸發）→ Domain（94・方法與法規）→ Tool（239・實際動 Revit）。

第一次來？先看 Skill / Domain / Tool 如何分工（5 分鐘懂全貌），再挑一個 Skill 試跑。完整哲學看 22 命題。
