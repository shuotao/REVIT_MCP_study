# BIM_MCP Image Assets

SVG assets in this folder follow the handoff naming rule:

`<page-stem>__<position>__<concept>.svg`

The visual direction is deliberately minimal: black background, white geometric marks, and sparse `#60a5fa` highlights. These assets are authored as deterministic SVG files so they remain reviewable in git and can be embedded with regular `<img>` tags.

## 2026-10 靜態優先規則

手繪 SVG 內的元素在 t=0 即可見；只允許每一幀都可見的循環動畫（例如 `.pulse`、`.flow`），不得以 `opacity:0` 或 `stroke-dashoffset` 當作進場前的起始狀態。原因：SVG 以 `<img>` 載入時，頁面的 CSS 與虛擬時鐘管不到圖內動畫，列印、另存 PDF、連結預覽與「減少動態」偏好看到的都是 t≈0 的畫面，進場動畫會讓圖變成一片黑。`skills__hero__grains.svg` 與 `domain__hero__grains.svg` 由 `scripts/gen-hero-grains.mjs` 產生，同樣的規則在產生器內處理。

放寬的規則：早期 `_IMAGE_PLAN_CODEX.md`（2026-05）針對手繪 SVG，禁止圖內出現中文與 3D 標記，該文件保留為歷史紀錄、不修改。這批插圖允許圖內含繁體中文，條件是：

- 每張圖旁邊的 HTML 文字必須載有同樣的資訊（圖不是唯一來源）；
- `alt` 用繁體中文，`<figcaption>` 註明「概念示意圖（AI 生成），非軟體畫面」；
- 圖內不得出現數字、版本號、錯誤碼、標誌或真人臉孔。
