# 增築梁的對話流程

執行 `create_beam_additions` 時，依下列順序收集使用者設定：

1. 讀取並保留使用者選取的來源梁 ID，先詢問「需要增築幾公分厚？」。將確認的厚度換算成 `depthMm`，作為新增梁深；寬度沿用各來源梁實際寬度。
2. 厚度確定後，再詢問「參考樓層是哪一層？Z 向偏移多少公分？」。以專案實際樓層解析 `referenceLevelId`，將含正負號的偏移換算為 `zOffsetMm`。
3. 若使用者已在本次任務明確提供其中設定，不重複詢問；只詢問尚缺的資料。不沿用其他批次的厚度、樓層或偏移當成使用者答案。
4. 設定齊全後才呼叫工具預覽。檢查所需類型與左右對正；新增梁高程完全依指定參考樓層及 Z 偏移，梁深依指定厚度。來源梁僅提供平面位置、方向、寬度及左右對正，不以來源梁頂面高程限制建置，也不要求新梁底與原梁頂銜接。
5. 在使用者已授權的建置範圍內，以新鮮 previewToken 正式建立。文字群組「編號」填「增築」。完成後核對實體、寬深、參考樓層、Z 偏移及編號。

厚度、參考樓層與 Z 偏移必須由本次使用者設定取得，不設隱含預設。互動詢問由呼叫工具的助理完成；Revit 命令不在交易中顯示詢問對話框。

本次待執行設定已確認為：厚度 35 公分、參考 GL、Z 偏移 +30 公分。這是本次輸入，不是工具的通用預設。
