# Abby 建置柱標準流程

使用者於 2026-10-24 明確指定。適用於「建置柱」「建柱」「從 CAD 建結構柱」等指令。

## 執行前集中確認

一次詢問以下三項，已有明確答案時沿用，不重複詢問：

1. 柱輪廓圖層名稱。
2. 基準樓層。
3. 頂部樓層。

使用者回覆即授權整套批次流程，不再逐根或逐階段詢問是否執行。這不會取代工具平台本身的核准機制，不得宣稱能關閉或繞過平台核准。

## 完整工作範圍

1. 讀取目前視圖 CAD 的指定柱輪廓圖層，使用實際模型座標與方向，排除尺寸表、圖例等非建築柱輪廓。
2. 找出對應柱號文字圖層與柱尺寸表（包含 CAD 下方表格），依位置與柱號配對；文字圖層無法唯一判定或配對歧義才集中提出必要問題。
3. 核對 CAD 單位、柱形狀、尺寸與上下樓層，確認不存在同位置及同高度範圍的既有柱。
4. 比對適用結構柱族群的實際尺寸參數。已有尺寸直接沿用；缺少尺寸時複製適用類型，設定並驗證尺寸後建置。不同截面形狀不可用矩形外接框替代；缺少適用族群時列出原因，不假稱已完成。
5. 批次建置柱，預設基準與頂部偏移皆為 0；使用者另有指定則依指定。不得改動其他既有類型尺寸。
6. 同步填寫實例的文字群組「編號」為 CAD 柱號，文字群組「Floor」為基準樓層代碼，例如 1FL.S.L → 1FL、B1FL.S.L → B1F。沿用使用者已確認的命名；無法判定代碼才集中澄清。
7. 以 Parameter.Definition.GetGroupTypeId() 精確辨識文字群組，不以內建標記或其他同名參數替代。缺少、唯讀或歧義參數必須列入未完成項目。
8. 核對柱數、位置、方向、實際斷面、上下樓層、偏移、柱號及 Floor，與尺寸表比對。回報建立／既有跳過／失敗／待確認數量及新增類型；需要時選取本批元素供檢視。

## 工具執行原則

- 先確認實際已載入工具及部署版本是否能完整處理上述流程，不能只因原始碼已編譯就宣稱 Revit 已載入。
- 優先沿用既有可用批次工具，一次傳入整批資料；不可把逐根工具迴圈宣稱為單次批次呼叫。
- 不為例行建模反覆修改或編譯。能力確有缺口時先說明具體缺口，集中修正與驗證，避免做一半才發現漏填欄位。
- 能同交易完成建置與填值時採同交易；若工具分成多次批次呼叫，持久保存新元素 ID，限定填值範圍，不重建已成功元素。
- 建柱完成但柱號或 Floor 未填，必須明確回報部分完成，不可稱整套流程完成。
- 本規則不授權修改或提交既有未追蹤的 .agents/skills、.codex。
